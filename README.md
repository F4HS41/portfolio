# 📐 Geometry Calculator & Portfolio (โปรแกรมคำนวณเรขาคณิตอเนกประสงค์)

โปรแกรมคำนวณพื้นที่และเส้นรอบรูปทางเรขาคณิต พัฒนาด้วยภาษา Python โดยต่อยอดจากโค้ดคำนวณพื้นที่สี่เหลี่ยมพื้นฐาน ให้สามารถรับค่าจากผู้ใช้และรองรับรูปทรงที่หลากหลายขึ้น

---

## ✨ ความสามารถของโปรแกรม (Features)
- 🔲 คำนวณพื้นที่และเส้นรอบรูปสี่เหลี่ยมมุมฉาก
- 🔺 คำนวณพื้นที่สามเหลี่ยม
- ⚪ คำนวณพื้นที่และเส้นรอบวงกลม
- 🔄 มีระบบเมนูวนซ้ำ สามารถคำนวณต่อเนื่องได้จนกว่าจะกดออกจากโปรแกรม

---

## 💻 ตัวอย่างโค้ด (Source Code)

```python
import math

def calculate_rectangle():
    width = float(input("กรอกความกว้าง: "))
    length = float(input("กรอกความยาว: "))
    print(f"พื้นที่สี่เหลี่ยม: {width * length:.2f} ตารางหน่วย")

def main():
    print("--- โปรแกรมคำนวณเรขาคณิต ---")
    calculate_rectangle()

if __name__ == "__main__":
    main()
